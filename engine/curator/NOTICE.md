# NOTICE — concept attribution

curator is an original implementation, but its core concept is inspired by
**lavish-axi** by **Kun Chen (kunchenguid)**, released under the MIT License:
the idea of a local review surface where an agent renders a plan as an HTML
artifact, the human annotates it in the browser, and the agent receives
structured feedback over a long-poll loop.

No code was copied from lavish-axi or any other of Kun Chen's tools
(no-mistakes, lavish-axi, gnhf). Everything in this directory was written
from scratch against a concept description only.
