# Worked examples

This folder holds one real run of Detent. It went through all seven stages on [Amanborn007/detent-demo#1](https://github.com/Amanborn007/detent-demo/pull/2).

The run folder `2026-10-20-amanborn007-detent-demo-1/` has the brief, the research, the plan, the decisions that were answered through curator, the recheck, and the ship evidence. The curator pages are in its `plans/` folder.

The git worktree is left out, because the code lives in the demo PR. Local paths, the username and the hostname are replaced, so you will see `$DETENT_ROOT`, `~`, `<user>` and `<host>` in the files. Nothing else was edited.

`scripts/export-example.sh` makes a folder like this from any run directory.
